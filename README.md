# Search on GTACars

A simple Firefox add-on that lets you Search on [GTACars](https://gtacars.net) from the right click context menu.

## Installation

Simply go to the [Firefox Add-ons page](https://addons.mozilla.org/en-US/firefox/addon/search-on-gtacars) to install!

## Usage

To search any text on any website on GTACars, just highlight it and click "Search on GTACars."
